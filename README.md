# 股票量化分析工具

输入股票代码，自动获取历史行情、计算技术指标、给出买卖点建议、机器学习涨跌预测，并对策略进行历史回测，最后生成文字报告与可视化图表。

> ⚠️ **风险提示**：本工具基于公开技术指标规则与统计学习模型生成分析结果，仅供技术研究与学习参考，**不构成任何投资建议**。股市有风险，入市需谨慎，请勿仅凭本工具的输出做出实际交易决策。

## 功能

- **多市场行情获取**：根据股票代码自动识别市场
  - 美股 / 港股：通过 [yfinance](https://github.com/ranaroussi/yfinance)（如 `AAPL`、`0700.HK`）
  - A股：通过 [akshare](https://github.com/akfamily/akshare)（6位数字代码，如 `600519`），未安装 akshare 或获取失败时自动降级为 yfinance / 本地缓存
- **技术指标**：MA(5/10/20/60)、EMA、MACD、RSI(14)、KDJ、布林带、ATR、OBV、成交量比等
- **买卖点信号**：多指标加权评分系统（均线金叉死叉、MACD交叉、RSI超买超卖、KDJ、布林带触及、放量确认），输出历史买卖点列表与当前操作建议、支撑/压力位
- **机器学习预测**：基于 scikit-learn 的梯度提升分类器 + 随机森林回归，按时间顺序切分训练/测试集，预测未来 N 个交易日的上涨概率与预期收益率，并给出样本外准确率与特征重要性
- **策略回测**：将信号规则转为多头择时策略，与买入持有基准对比累计收益、年化收益、最大回撤、胜率、夏普比率
- **报告与图表**：中文文字报告 + K线/均线/布林带/买卖点标注图 + MACD/RSI 副图（PNG）

## 安装

```bash
pip install -r requirements.txt
# 如需分析 A 股，额外安装：
pip install akshare
```

## 使用方法

```bash
# 美股
python main.py AAPL

# A股（自动识别6位代码）
python main.py 600519 --period 3y

# 港股
python main.py 0700.HK --predict-days 10

# 离线演示模式：无需联网，使用模拟生成的行情数据体验完整流程
python main.py 600519 --demo

# 使用本地CSV历史行情文件（当运行环境无法联网获取行情时）
python main.py 002141 --csv ./002141_history.csv
```

参数说明：

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `code` | 股票代码（必填） | - |
| `--period` | 拉取历史数据时长，如 `1y`/`2y`/`5y`/`500d` | `2y` |
| `--predict-days` | 预测未来 N 个交易日走势 | `5` |
| `--no-chart` | 跳过图表生成 | - |
| `--demo` | 离线演示模式，使用随机模拟数据 | - |
| `--csv` | 使用本地CSV文件而非联网获取，需包含日期/开盘/最高/最低/收盘/成交量列（支持中英文表头） | - |

> 💡 若运行环境的出网策略限制访问 Yahoo Finance / akshare 等行情源（常见于沙盒/CI环境），可先在能联网的机器或终端下载好历史行情CSV，再用 `--csv` 参数离线分析。

图表默认保存在 `output/<代码>_chart.png`，行情数据缓存在 `data_cache/`。

## 项目结构

```
main.py                CLI 入口，串联各模块并输出报告
src/
  data_fetcher.py       行情获取（yfinance / akshare / 缓存 / 模拟数据）
  indicators.py         技术指标计算
  signals.py            买卖点信号生成（规则加权评分）
  predictor.py          机器学习涨跌概率与目标价预测
  backtester.py         信号策略历史回测
  report.py             文字报告与图表渲染
tests/                  离线单元测试（基于模拟数据，无需联网）
```

## 原理简述

1. **信号评分**：每个交易日根据均线交叉、MACD交叉、RSI区间、KDJ交叉、布林带触及、放量情况累加/扣减分数，综合评分达到阈值（±3）即视为强烈买/卖点；当前评分映射为「买入 / 偏多 / 观望 / 偏空 / 卖出」五档建议。
2. **预测模型**：以技术指标及其衍生特征（价格相对均线偏离度、量比、波动率、滞后收益率等）为特征，标签为未来 N 日是否上涨/涨跌幅，采用严格按时间顺序的训练/测试切分（不打乱顺序，避免未来数据泄露），分别训练分类模型（涨跌概率）与回归模型（预期收益率/目标价）。
3. **回测**：完全基于历史信号评分做多/清仓的简化择时策略，与同期买入持有对比，用于评估规则信号的历史有效性，**不代表未来表现**。

## 局限性

- 技术指标与机器学习模型无法预知突发消息面、政策面、财报等基本面因素带来的价格跳变。
- 回测未计入交易佣金、印花税、滑点等实际交易成本。
- 机器学习预测样本外准确率通常有限（股价短期走势本质上接近随机游走），预测结果应结合概率与置信度谨慎参考，而非视为确定性结论。
